# Security

This project runs a loopback-only development server and has no hosted model service or account system. Do not expose the Python development server to the public internet.

Treat subtitles, course files and imported progress as untrusted data. Keep private subtitles outside the served directory. Do not commit API keys, cookies, personal progress or third-party copyrighted transcripts.

For a suspected vulnerability, use this repository's private vulnerability reporting feature when available. If it is unavailable, open an issue requesting a private contact channel without publishing exploit details or personal data.

Supported version: latest 0.1.x. Reports should include a minimal original fixture and reproduction steps, never real credentials.
