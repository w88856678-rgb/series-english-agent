# 和你的学习 Agent 一起看剧学英语

**先认识几个表达，再去剧情里遇见它们。**

一集一练把学习分成三个自然的时刻：看剧前预习、看剧时辨认、看剧后开口。你可以按自己的节奏，只练今天想练的部分。

## 第一次见面，告诉它你想怎么学

> 用 $series-english 帮我学英语。我喜欢轻松的喜剧，水平大约是 B1，希望用中文解释，每天练 10 分钟。

接着指定剧集，或提供自己的英语字幕：

> 今天学《老友记》第一季第一集。先挑 10 个实用表达，帮我做成可以听发音的课程。

Skill 会帮 Agent 整理表达、出处和释义，Agent 再把内容准备成听读课程。如果找不到对应字幕，它会请你提供文件，再继续制作。

## 预习时，这样问

| 你想解决的问题 | 可以直接对 Agent 说 |
| --- | --- |
| 意思懂了，但不知道怎么用 | “用一个生活场景解释这个表达，再给我一句原创例句。” |
| 想分清相似表达 | “这两个说法有什么区别？什么时候用哪一个？” |
| 今天不想学太多 | “先从本集挑 5 个最实用的表达，带我逐个练。” |
| 想练习开口 | “给我一个情景，让我用这个表达回答。等我说完再纠错。” |

打开配套网页，词组和例句都能点播。可以放慢语速，也可以连续听读。先听清，再跟着说一遍。

## 看剧时，留意表达出现的那一刻

在你平时使用的平台播放正片。听到刚学过的表达，看看是谁对谁说、语气如何、发生了什么。

遇到新的疑问，记下那一句或那个场景，看完再问 Agent。你不需要为了学完整张词表而不断打断剧情。

## 看完后，用一小轮练习收尾

先在网页隐藏中文，试着回忆。再把还不熟悉的表达标记为“待复习”。

点击“导出学习进度”，把文件发给 Agent：

> 用 $series-english 按这份记录带我复习。先来 5 道题，一次问一道，不要提前告诉我答案。

想练得更贴近生活，可以继续说：

> 用今天的表达和我模拟一次朋友聚会。请根据我的回答接着聊，并帮我改进不自然的说法。

Agent 会根据你交给它的记录选择练习，等待你的回答，再讲解。练习后可以回网页更新“已掌握”或“待复习”。

## 下一集，继续积累

重复表达会留在后续课程里，并标注为复习词。你可以快速过一遍熟词，把更多注意力放在新用法上。

网页会为已掌握的词安排后续复习时间；你下次打开时可以查看到期词。它不会自动发送提醒，也不会把浏览器里的进度实时传给 Agent，需要你主动导出。
